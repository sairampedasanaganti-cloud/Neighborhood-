# User Roles & Community Member Model

## 1. The Community Member Model
In NeighborLink, **there is no permanent "Volunteer" role**. Every registered user is a **Community Member**. 

A single Community Member can:
- 🤝 **Need Help**: Request assistance from nearby neighbors for age-specific needs.
- 🧑‍🤝‍🧑 **Find Companionship / Company**: Look for neighbors to share activities, walks, or hobby practice with.
- 🌱 **Offer Help**: Browse open requests in their community and assist a fellow neighbor.

A person can request help today and help another person tomorrow.

## 2. Age-Determined Interfaces
All community members belong to one of four age groups (calculated automatically from birth age):
- **Teenager (10–17)**: Age-appropriate categories, safety restrictions, safe community interaction.
- **Young Adult (18–25)**: Academic, technical, career, and active companionship categories.
- **Adult (26–59)**: Family support, elderly parent care, errands, household, and community categories.
- **Senior Citizen (60+)**: High-contrast, large-button, accessible interface with fewer choices and large typography.

## 3. Administrator Role (`role: 'admin'`)
Platform administrators oversee safety, moderation, and community health:
- Monitor live emergency broadcasts.
- Verify, suspend, or reactivate community members.
- Moderate requests and inspect platform activity.
- Review and resolve user safety reports (Inappropriate Behaviour, Safety Concerns, Misuse, False Requests).
- Admin routes are protected at both frontend and backend API levels.
